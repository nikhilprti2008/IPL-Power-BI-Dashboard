## 📌 Project Overview



This project focuses on analyzing Indian Premier League (IPL) data using Microsoft Power BI. The objective is to transform raw cricket data into meaningful insights through interactive dashboards and data visualizations.

The dashboards provide an analytical view of IPL performance, helping users explore team statistics, match trends, player performance, and other important aspects of the tournament.

## 🎯 Project Objectives

- Analyze IPL data to identify meaningful patterns and trends.
- Explore team and player performance.
- Compare performance across different IPL seasons.
- Create interactive dashboards for data exploration.
- Convert raw data into actionable insights.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and KPIs.
- **Data Visualization** – Interactive reports and analytical insights.

## ⚙️ Project Workflow

1. Imported IPL dataset into Power BI.
2. Cleaned and transformed the data.
3. Prepared the data for analysis.
4. Created calculated measures using DAX.
5. Designed interactive dashboards.
6. Analyzed the results and identified key insights.
